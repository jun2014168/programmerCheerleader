# 程序员鼓励师（Programmer Cheerleader）

一个 Trae 技能插件：把你的 AI 助手变成陪伴编程情绪的鼓励师——报错时有人安慰，过关时有人庆祝，随时可以说「夸夸我」。

三种风格随时切换：**温暖治愈** / **幽默段子手** / **毒舌反差萌**。内置防打扰频率控制、勿扰模式、事件误判纠偏与情绪安全边界。

## 安装

### 方式一：从插件市场安装（上架后可用）

在插件市场 / 技能市场搜索「程序员鼓励师」，点击安装，然后对 AI 说「鼓励师上线」。

### 方式二：手动安装技能

1. 克隆或下载本仓库；
2. 将 `skills/programmer-cheerleader` 文件夹复制到：
   - 项目级（仅当前项目可用）：`<你的项目>/.trae/skills/`
   - 全局（CN 版，所有项目可用）：`~/.trae-cn/skills/`
   - 全局（国际版）：`~/.trae/skills/`
3. 重开一个会话，对 AI 说「**鼓励师上线**」（本地记忆文件 `memory.json` 首次使用时自动生成）。

### 方式三：让 Trae 帮你装

对你的 AI 助手说：「从 https://gitcode.com/u013257731/ProgrammerCheerleader 安装这个技能」。

## 使用指令

| 指令 | 作用 |
|---|---|
| 鼓励师上线 / 鼓励师下线 | 开启 / 关闭人设 |
| 切温暖 / 切幽默 / 切毒舌 | 切换说话风格 |
| 夸夸我 / 安慰我 / 吐槽一下 | 主动聊天陪伴 |
| 勿扰 / 退出勿扰 | 静默累积动态 / 汇总送达 |
| 少来点 / 太冷漠了 | 降低 / 恢复主动鼓励频率 |
| 这不该鼓励 | 该类事件当日静默 |
| 忘了这些 | 清空陪伴记忆 |

## 工作方式

- 鼓励师只对**会话内可观察**的编程事件主动鼓励（构建/测试输出、你粘贴的报错、git 提交），不做后台监听，识别没把握时保持沉默；
- 主动鼓励受频率规则约束（同类挫败冷却 15 分钟，每小时最多 3 条），聊天不受限制；
- 毒舌风格可调侃代码与 bug，但绝不贬低你本人；检测到强烈负面情绪时自动切换温暖模式并建议寻求专业帮助。

## 插件包结构

本仓库同时是 Trae 插件包（对齐官方纯技能型插件规范）：

```text
├── .trae-plugin/plugin.json   # 插件清单
├── assets/icon.svg            # 图标
└── skills/programmer-cheerleader/
    ├── SKILL.md               # 人设核心逻辑
    └── references/phrasebook.md  # 话术库
```

## 隐私

陪伴记忆仅保存在本地 `memory.json`（已列入 `.gitignore`），不上传、不随仓库分发、不用于生成鼓励以外的用途。
